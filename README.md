# Работа со списком — Jetpack Compose

Откройте эту папку в Android Studio и дождитесь Gradle Sync. Выберите конфигурацию `app` и устройство, затем Run.

Приложение начинает с пустого списка. Кнопка добавляет последовательно пронумерованные квадраты. Нечётные номера синие, чётные красные. Вертикальная ориентация использует три колонки, горизонтальная — четыре (`values-land`). Кнопка размещена под сеткой, не перекрывает её и учитывает системные отступы.

Количество хранится в `rememberSaveable`, без SharedPreferences, базы данных и записи файлов. При повороте Activity пересоздаётся, количество восстанавливается. Строки, цвета, размеры и число колонок определены в Android resources. Разрешение INTERNET отсутствует. В исходниках нет Log.

## Проверка

1. Повернуть экран при пустом списке.
2. Добавить 15 элементов, повернуть экран и проверить количество и четыре колонки.
3. Добавить ещё элементы, прокрутить список до конца и проверить видимость последнего квадрата и кнопки.
4. Вернуть портретную ориентацию и проверить три колонки.

## Сборка

Windows: `gradlew.bat :app:assembleDebug`

APK после успешной сборки: `app/build/outputs/apk/debug/app-debug.apk`.

## Git

Локальные настройки SDK и результаты сборки исключены через `.gitignore`. Для сдачи создайте удалённый репозиторий, добавьте его как `origin` и отправьте код. Учётные данные в проекте не нужны.
